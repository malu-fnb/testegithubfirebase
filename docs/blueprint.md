# **App Name**: CampusGate Staff

## Core Features:

- Employee Owner Directory: Comprehensive interface to register and manage staff profiles including departments and roles.
- License Plate Ledger: A registry for vehicle details with multi-vehicle support for single owners.
- Real-time Access Control: One-click registration for vehicle entry and exit timestamps to monitor lot usage.
- AI Plate Assistant tool: An AI-powered utility to automatically format and validate plate numbers and predict vehicle metadata.
- Global Admin Search: Powerful search utility to instantly find vehicle details using partial license plates or staff names.
- Activity History log: Audit trail displaying past entries and exits for security reporting and traffic analysis.

## Style Guidelines:

- Primary Color: #a91f21 (Academic Crimson) used for primary branding and headers.
- Accent Color: #cc9934 (Traditional Gold) used for buttons, interactive elements, and state indicators.
- Background Color: #fdfefe (Arctic White) provides a clean, airy base for a sophisticated institutional feel.
- Headline and body font: 'Inter' to maintain a machined, objective, and neutral look suitable for administrative oversight.
- Structured dashboard layout with distinct cards for employee registration and live gate management.
- Monolinear, geometric icons to denote 'Entry', 'Exit', 'Employee', and 'Security'.
- Fluid micro-interactions when registering entries to provide immediate visual confirmation.
